# Changelog

## [1.0.0] - 2026-09-01

### Added
- 18 SolidJS components: Accordion, Avatar, Badge, CommandPalette, DataTable, DatePicker, ErrorBoundary, FileUpload, FormField, Modal, Pagination, Popover, Select, Skeleton, Tabs, ThemeToggle, Toast, Tooltip
- 3 Astro components: BaseLayout, Nav, Footer
- 5 design themes: Spatial Materialism, Amoebic UI, Brutalist, Tokyo Night, Arctic Dawn
- Design token system with CSS custom properties
- Hooks: useTheme, useMediaQuery, useReducedMotion, useLocalStorage
- Utilities: security headers, SEO helpers
- Starlight plugin for documentation sites
- Interactive storybook with 16 demo pages
- Full documentation for all components
- TypeScript types for all components
- Accessibility support (ARIA, keyboard navigation)
- Theme toggle with localStorage persistence

### Fixed
- useLocalStorage.ts type error with SolidJS generic overload
- Showcase workspace configuration

## [0.1.0] - 2026-08-15

### Added
- Initial release with 8 components
- BaseLayout, Nav, Footer Astro components
- Design tokens (Spatial Materialism theme)
- ThemeToggle, ErrorBoundary components
- DataTable, FormField, Modal components
