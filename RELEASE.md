# Pediment v1.0.0 Release

## What's New

Pediment v1.0.0 is a production-ready UI framework for Astro + SolidJS with 18 accessible components, 5 design themes, and comprehensive documentation.

### Components (18)
- **Layout**: BaseLayout, Nav, Footer
- **Data Display**: DataTable, Pagination, Badge, Avatar
- **Forms**: FormField, Select, DatePicker, FileUpload
- **Feedback**: Toast, Modal, Tooltip, ErrorBoundary
- **Navigation**: Tabs, Accordion, CommandPalette
- **Utility**: ThemeToggle, Skeleton

### Design System
- 5 themes: Spatial Materialism, Amoebic UI, Brutalist, Tokyo Night, Arctic Dawn
- CSS custom properties for easy customization
- Typography scale (8 levels)
- Spacing scale
- Elevation shadows (6 levels)

### Developer Experience
- TypeScript-first with full type support
- Interactive storybook (16 demo pages)
- Full documentation for all components
- CLI scaffolding via forgeyard
- Starlight plugin for docs sites

## Quick Start

```bash
# Install
bun add @pediment/components @pediment/tokens @pediment/hooks

# Or scaffold a new project
forgeyard init my-project --template astro-solidjs
```
