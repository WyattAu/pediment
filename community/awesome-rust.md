# Pediment - Production-Ready UI Framework

A comprehensive UI framework for Astro + SolidJS with 18 accessible components, design tokens, and 5 themes.

## Features

- 18 accessible SolidJS components (DataTable, Modal, Select, Toast, Tabs, Accordion, Badge, Avatar, Pagination, Tooltip, Popover, CommandPalette, FileUpload, DatePicker, Skeleton, ErrorBoundary, ThemeToggle, FormField)
- 5 design themes with CSS custom properties (midnight-navy, tokyo-night, arctic-dawn, solaris, light)
- TypeScript-first with full type safety
- Works with Astro, Next.js, or standalone SolidJS
- CLI scaffolding via forgeyard
- Design token system with Spatial Materialism and Amoebic UI patterns
- `@layer base, components, utilities` support for Tailwind v4
- Security headers, SEO, and analytics utilities
- Starlight plugin for design system integration
