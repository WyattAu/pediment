### Description
Shared design tokens, components, and utilities for Astro+SolidJS+Starlight+Cloudflare projects. Provides Spatial Materialism + Amoebic UI design systems, 5 theme variants, and production-grade component library.

### Repository
https://github.com/WyattAu/pediment

### Crates.io / npm
- @pediment/tokens (npm)
- @pediment/components (npm)
- @pediment/hooks (npm)
- @pediment/utils (npm)
- @pediment/starlight (npm)

### Key Features
- CSS-first design tokens (Tailwind v4 @theme)
- 5 themes: midnight-navy, tokyo-night, arctic-dawn, solaris, light
- Spatial Materialism (elevation, shadows, z-index)
- Amoebic UI (organic radii, fluid gradients, easing)
- Brutalist design system elements
- Astro components (BaseLayout, Nav, Footer)
- SolidJS islands (ThemeToggle, ErrorBoundary, ToastProvider)
- Starlight plugin for documentation sites
- Cloudflare Pages deployment
