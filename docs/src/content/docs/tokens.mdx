---
title: Design Tokens
description: Reference for Pediment's design token system
---

Design tokens are the visual design atoms of your system — specific, reusable values that maintain consistency across your application.

## Installation

```bash
bun add pediment-tokens
```

## Import

```css
/* Global styles */
@import "pediment-tokens";
```

Or import specific token categories:

```css
@import "pediment-tokens/colors";
@import "pediment-tokens/spacing";
@import "pediment-tokens/typography";
```

## Usage in JavaScript

```typescript
import { tokens } from "pediment-tokens";

console.log(tokens.colors.primary[500]); // "#3b82f6"
console.log(tokens.spacing[4]); // "16px"
```

## Design Guidelines

- Use tokens consistently across your application
- Avoid hardcoding values that exist as tokens
- Extend tokens via CSS custom properties for theming
- Document any custom tokens added to your project
