Pediment is a comprehensive design system for building modern web applications with Astro, SolidJS, Starlight, and Cloudflare.

## Features

- **Design Tokens**: Consistent spacing, colors, typography, and more
- **UI Components**: Pre-built, accessible components for common use cases
- **Hooks**: Reusable SolidJS hooks for state management and utilities
- **Starlight Integration**: Seamless integration with Astro's documentation framework

## Quick Start

```bash
# Install via CLI
bunx pediment init my-project
cd my-project
bun install
bun run dev
```

Or add to an existing project:

```bash
bun add pediment
```

## Packages

| Package | Description |
|---------|-------------|
| `pediment-tokens` | Design tokens for consistent theming |
| `pediment-components` | SolidJS UI components |
| `pediment-hooks` | Reusable SolidJS hooks |
| `pediment-utils` | Utility functions |
| `pediment-starlight` | Starlight plugin for design system integration |
