Pediment provides a flexible theming system built on CSS custom properties, making it easy to customize the look and feel of your application.

## Installation

```bash
bun add pediment-tokens
```

## How Theming Works

Pediment uses CSS custom properties (variables) for theming. All components reference these variables, allowing you to override the entire design system by changing a few values.

## Built-in Themes

### Light Theme (Default)

```css
@import "pediment-tokens";

/* Light theme is applied by default */
```

### Dark Theme

```css
@import "pediment-tokens";

[data-theme="dark"] {
  --color-primary-500: #60a5fa;
  --color-neutral-0: #1f2937;
  --color-neutral-900: #f9fafb;
  /* Override other tokens as needed */
}
```

### System Preference

```css
@media (prefers-color-scheme: dark) {
  :root {
    --color-primary-500: #60a5fa;
    /* Dark theme overrides */
  }
}
```

## Creating a Custom Theme

### 1. Define Your Tokens

```css
/* themes/my-brand.css */
[data-theme="my-brand"] {
  /* Colors */
  --color-primary-50: #f0fdf4;
  --color-primary-100: #dcfce7;
  --color-primary-500: #22c55e;
  --color-primary-600: #16a34a;
  --color-primary-700: #15803d;

  /* Typography */
  --font-sans: "Inter", system-ui, sans-serif;
  --font-mono: "JetBrains Mono", monospace;

  /* Spacing */
  --space-4: 20px;

  /* Border Radius */
  --radius-md: 0.5rem;
}
```

### 2. Apply the Theme

```html
<html data-theme="my-brand">
  <head>
    <link rel="stylesheet" href="/themes/my-brand.css" />
  </head>
  <body>
    <!-- Your app content -->
  </body>
</html>
```

### 3. Toggle Themes in JavaScript

```typescript
import { createSignal } from "solid-js";

const [theme, setTheme] = createSignal("light");

function toggleTheme() {
  const newTheme = theme() === "light" ? "dark" : "light";
  setTheme(newTheme);
  document.documentElement.setAttribute("data-theme", newTheme);
  localStorage.setItem("theme", newTheme);
}

// Initialize from localStorage
const savedTheme = localStorage.getItem("theme") || "light";
document.documentElement.setAttribute("data-theme", savedTheme);
```

## Theme Properties

### Colors

Override the color palette:

```css
[data-theme="custom"] {
  --color-primary-500: #your-primary;
  --color-secondary-500: #your-secondary;
  --color-success-500: #your-success;
  --color-warning-500: #your-warning;
  --color-error-500: #your-error;
}
```

### Typography

Customize fonts and sizes:

```css
[data-theme="custom"] {
  --font-sans: "Your Font", system-ui, sans-serif;
  --font-mono: "Your Mono Font", monospace;
  --text-base: 16px;
  --leading-normal: 1.6;
}
```

### Spacing

Adjust spacing scale:

```css
[data-theme="custom"] {
  --space-1: 5px;
  --space-2: 10px;
  --space-4: 20px;
}
```

### Border Radius

Change corner rounding:

```css
[data-theme="custom"] {
  --radius-md: 0;
  --radius-lg: 0;
  --radius-xl: 0;
}
```

## Advanced: Theme Inheritance

Themes can inherit from other themes:

```css
[data-theme="dark"] {
  /* Base dark tokens */
}

[data-theme="dark-high-contrast"] {
  /* Override specific tokens for high contrast */
  --color-primary-500: #93c5fd;
  --color-neutral-900: #000000;
}
```

## Example: Brand Theme

```css
/* acme-theme.css */
[data-theme="acme"] {
  /* Brand Colors */
  --color-primary-500: #ff6b35;
  --color-primary-600: #e55a2b;
  --color-secondary-500: #004e89;

  /* Typography */
  --font-sans: "Poppins", system-ui, sans-serif;

  /* Custom Properties */
  --brand-gradient: linear-gradient(135deg, #ff6b35, #004e89);
}
```

```tsx
// Usage in components
<div style={{ background: "var(--brand-gradient)" }}>
  Welcome to ACME
</div>
```

## Design Guidelines

- Limit your color palette to 5-7 main colors
- Ensure sufficient contrast between text and backgrounds
- Test themes in both light and dark modes
- Document all custom tokens for team reference
- Use semantic naming for custom tokens
- Provide fallback values for critical tokens

## Accessibility

- Maintain WCAG 2.1 AA contrast ratios (4.5:1 for text)
- Don't rely solely on color to convey information
- Test themes with color blindness simulators
- Ensure focus indicators are visible in all themes
- Provide a way to reduce motion for animations

## Best Practices

1. **Start with defaults**: Only override what you need to change
2. **Use semantic tokens**: Reference tokens by purpose, not value
3. **Document changes**: Keep a record of theme customizations
4. **Test thoroughly**: Verify all components work with your theme
5. **Consider edge cases**: Test with long text, missing images, etc.
